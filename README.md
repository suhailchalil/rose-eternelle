# Rose Éternelle

A scroll-driven fragrance film that moves from an opening video into a layered WebGL world, then travels through clouds to a second scene. Built as a frontend experience with vanilla JavaScript and a vendored Three.js module.

**[View the live demo](https://suhailchalil.github.io/rose-eternelle/)**

![Rose Éternelle fragrance experience preview](preview.webp)

## Run locally

```bash
python -m http.server 8900
```

Open <http://localhost:8900>. Use a current browser with WebGL enabled.

## Highlights

- Seamless handoff from the opening film to the live scene
- One shared camera for environmental layers, foreground particles, and product frames
- Scroll-controlled depth, motion, and a cloud transition between two visual worlds
- Self-hosted, optimised media and local Three.js module

This repository is a visual concept and contains only the media required to run it. Source artwork, working files, and unused exports are excluded. It does not include commerce or account features.
